# Formato Bello

Un formato di Magic: The Gathering fatto in casa, per giocare fra amici con le
carte di quando eravamo ragazzi: tanta nostalgia, mazzi tutti diversi, un
comandante e qualche carta moderna in dosi controllate.

## Link utili

- **Deck builder:** https://kimmimaru90.github.io/formato-bello/deck_builder.html
- **Regolamento completo:** [REGOLAMENTO.md](REGOLAMENTO.md)

## Le regole in breve

- **Carte classiche:** quelle con almeno una stampa uscita entro
  *Liberatori di Kamigawa* (giugno 2005).
- **Mono colore:** un solo colore per mazzo, più carte incolori. Ogni
  giocatore ha il suo colore.
- **Comandante:** una creatura leggendaria classica del tuo colore. Parte
  dalla zona di comando, da lì si lancia, e ogni volta che la rilanci costa
  {2} in più; se va nel cimitero o in esilio torna nella zona di comando.
  Niente danno da comandante. Alcuni comandanti sono vietati (regola 8.3).
- **Copia singola:** ogni carta una volta sola, tranne le terre base.
- **Mazzo:** almeno 60 carte, comandante compreso.
- **Bombe:** al massimo 6 carte moderne (uscite dopo Liberatori).
- **Lista Punti:** le carte più forti costano punti; ogni mazzo ne ha **8**.
  Anche le bombe hanno il loro valore (2, 1 o 0); quelle non ancora
  valutate costano almeno 1 punto se sono mitiche o dei set Modern Horizons.
- **Vietati:** planeswalker, combo che vincono in un turno, carte "vinci la
  partita", posta, set burloni, compagni e la banlist del regolamento.
- Si gioca con le proxy, preferibilmente con il layout dell'epoca.

## Come si usa il deck builder

1. Scegli il tuo nome e il tuo colore.
2. Scegli il **comandante**: cercalo per nome (in italiano o in inglese)
   oppure prendilo fra i più giocati del tuo colore.
3. Costruisci il **mazzo**: con il **+** cerchi e aggiungi qualsiasi carta del
   tuo colore o incolore, classica o bomba. Su ogni carta vedi quanti punti
   costa. Con il bottone 🖼 scegli l'immagine (la stampa) di ogni carta.
4. Se vuoi una mano, premi **🎲 Modalità draft**: ti propone tre carte alla
   volta finché il mazzo non è pieno. Puoi saltare o uscire quando vuoi.
5. Premi **Esporta per Fede (.json)** e manda il file a Fede: controlla i
   punti e prepara le proxy da stampare.

Il mazzo resta salvato solo nel tuo browser: per riprenderlo altrove usa
**Importa .json** (funziona anche con i file delle versioni precedenti).
Serve una connessione a Internet.
